# Credit Risk Assessment Application

An end-to-end Machine Learning web application designed to predict and analyze credit risk based on financial data.

## 🚀 Features
- **Data Engineering:** Automated processing of financial datasets.
- **Model Training:** Machine learning models trained to classify credit risk.
- **Interactive UI:** A user-friendly web interface to input applicant details and view instant risk predictions.

## 🛠️ Project Structure
- `app.py`: The main web application file.
- `train_model.py`: Script to train and evaluate the machine learning model.
- `generate_data.py`: Script used to create or preprocess the dataset.
- `credit_data.csv`: The dataset containing credit records.
- `credit_model.pkl`: The trained serialization of the machine learning model.
- `requirements.txt`: List of dependencies and packages required to run the project.

## 💻 Local Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python app.py
   ```
